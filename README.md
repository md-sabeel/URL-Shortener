# 🔗 URL Shortener (Frontend Only)

A modern and attractive URL Shortener built using **HTML, CSS, and JavaScript** with a real public API.

## 🚀 Features
- Shorten long URLs using API
- Copy to clipboard
- Toast notifications
- Glassmorphism UI
- Responsive design
- Navbar & Footer

## 🌐 API Used
TinyURL API (BEST for frontend)

✔ Free

✔ No API key

✔ No CORS issue

✔ Works on GitHub Pages

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
